# Plan: Split Categories and Licenses Pages

## Goal
Split the combined categories-licenses page into two separate pages:
1. Categories page: `/[lang]/admin/categories`
2. Licenses page: `/[lang]/admin/licenses`

Update the admin dashboard to show separate links for each.

## Files to Modify/Create

### 1. Create new categories page
- `front\src\app\[lang]\admin\categories\page.tsx`
- Based on existing categories-licenses page but showing only categories tab

### 2. Create new licenses page
- `front\src\app\[lang]\admin\licenses\page.tsx`
- Based on existing categories-licenses page but showing only licenses tab

### 3. Update admin dashboard links
- `front\src\app\[lang]\admin\page.tsx`
- Replace single categories-licenses link with two separate links

### 4. Remove or repurpose old page
- `front\src\app\[lang]\admin\categories-licenses\page.tsx`
- Can be removed after verifying new pages work

## Implementation Details

### New Categories Page
- Import and use CategoriesLicensesTab component
- Set activeSubTab to 'categories' by default
- Hide sub-tab navigation (or modify component to accept prop to hide tabs)
- Show only categories header and content

### New Licenses Page
- Import and use CategoriesLicensesTab component
- Set activeSubTab to 'licenses' by default
- Hide sub-tab navigation
- Show only licenses header and content

### Admin Dashboard Updates
- Replace the single categories-licenses link object with two separate objects:
  - Categories link: href: `/${locale}/admin/categories`
  - Licenses link: href: `/${locale}/admin/licenses`
- Update titles, descriptions, and icons appropriately

## Component Refactoring Options
Option 1: Modify CategoriesLicensesTab to accept a `hideSubTabs` prop
Option 2: Create simplified versions of the tab content for each page
Option 3: Use CSS to hide sub-tabs when on dedicated pages

Recommended: Option 1 - add prop to CategoriesLicensesTab to conditionally render sub-tabs

## Steps
1. Create categories page file
2. Create licenses page file
3. Update CategoriesLicensesTab to accept hideSubTabs prop
4. Update admin dashboard links
5. Verify functionality works correctly
6. Remove old categories-licenses page (optional, can keep for backward compatibility)
