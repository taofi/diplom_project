# Схема работы чатов

## Общее описание

Система чатов связывает покупателя с продавцом (художником). Чат может быть:
- **Привязан к товару** — покупатель пишет по конкретному товару
- **Без привязки к товару** — покупатель просто пишет продавцу

Из чата можно **создать заказ на кастомную работу / изменение товара** — продавец устанавливает цену и сроки.

> **Важно:** Каждый товар имеет `seller_id` — ID продавца, который его добавил. Только этот продавец видит чаты, привязанные к его товарам.

> Схема БД для чатов описана в [database-schema.md](database-schema.md) — таблицы 21-25.

## Диаграмма потоков

```mermaid
flowchart TD
    A[Покупатель открывает страницу товара] --> B{Хочет написать продавцу?}
    B -->|Да| C[Создаёт чат привязанный к товару]
    B -->|Нет| D[Покупатель открывает профиль продавца]
    D --> E[Создаёт общий чат без товара]

    C --> F[Отправляет сообщение]
    E --> F

    F --> G[Продавец видит чат в своей панели]
    G --> H[Продавец отвечает]
    H --> I{Нужна кастомная работа?}

    I -->|Да| J[Продавец создаёт предложение в чате]
    J --> K[Указывает цену и сроки]
    K --> L{Покупатель согласен?}

    L -->|Да| M[Покупатель принимает - создаётся custom_order]
    L -->|Нет| N[Покупатель отклоняет или запрашивает изменения]
    N --> J

    I -->|Нет| O[Продолжается обычная переписка]
```

## Схема доступа

```mermaid
flowchart LR
    subgraph Покупатель
        U1[Видит свои чаты]
        U2[Может создать чат]
        U3[Может отправить сообщение]
        U4[Может принять/отклонить предложение]
    end

    subgraph Продавец
        S1[Видит чаты только по СВОИМ товарам]
        S2[Видит общие чаты адресованные ему]
        S3[Может ответить на сообщение]
        S4[Может создать предложение с ценой и сроками]
    end

    subgraph Доступ
        D1[product.seller_id = текущий продавец]
        D2[chat_room.seller_id = текущий продавец]
    end

    S1 --> D1
    S2 --> D2
```

## Жизненный цикл кастомного заказа

```mermaid
stateDiagram-v2
    [*] --> in_progress : Покупатель принял предложение
    in_progress --> review : Продавец загрузил результат
    review --> completed : Покупатель одобрил
    review --> revision : Покупатель запросил доработку
    revision --> review : Продавец загрузил новую версию
    in_progress --> cancelled : Отмена
    review --> cancelled : Отмена
```

## Сценарии использования

### Сценарий 1: Покупатель пишет по товару

```mermaid
sequenceDiagram
    participant B as Покупатель
    participant S as Система
    participant P as Продавец

    B->>S: Открывает страницу товара
    B->>S: Нажимает Написать продавцу
    S->>S: Создаёт chat_room с product_id и seller_id из products.seller_id
    B->>S: Отправляет сообщение
    S->>P: Уведомление о новом чате
    P->>S: Читает сообщение
    P->>S: Отвечает
    S->>B: Уведомление об ответе
```

### Сценарий 2: Покупатель пишет продавцу напрямую

```mermaid
sequenceDiagram
    participant B as Покупатель
    participant S as Система
    participant P as Продавец

    B->>S: Открывает профиль продавца
    B->>S: Нажимает Написать
    S->>S: Создаёт chat_room без product_id
    B->>S: Отправляет сообщение
    S->>P: Уведомление о новом чате
    P->>S: Отвечает
```

### Сценарий 3: Создание заказа из чата

```mermaid
sequenceDiagram
    participant B as Покупатель
    participant S as Система
    participant P as Продавец

    B->>S: Хочу изменить иллюстрацию
    P->>S: Создаёт предложение: цена 500р, срок 3 дня
    S->>S: chat_messages type=offer + chat_offers status=pending
    S->>B: Показывает карточку предложения

    alt Покупатель принимает
        B->>S: Принимает предложение
        S->>S: chat_offers.status = accepted
        S->>S: Создаёт custom_order из предложения
        S->>P: Уведомление - заказ создан
        P->>S: Загружает результат
        S->>S: custom_order_revisions + статус review
        B->>S: Одобряет результат
        S->>S: custom_order.status = completed
    else Покупатель отклоняет
        B->>S: Отклоняет предложение
        S->>S: chat_offers.status = declined
        P->>S: Создаёт новое предложение с другой ценой
    end
```
