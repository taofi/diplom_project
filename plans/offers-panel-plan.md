# План: Перенос отображения offers в отдельную панель справа от чата + WebSocket обработка

## Текущее состояние
- Текущая схема: `grid-cols-1 lg:grid-cols-3` (список чатов | окно чата | пусто)
- Offers рендерятся внутри ChatWindow вместе с сообщениями (строки 265-272 в ChatWindow.tsx)
- WebSocket обработчики в ChatContext:
  - `offer:created` - добавление нового предложения
  - `offer:statusChanged` - изменение статуса предложения
  - `offer:priceChanged` - изменение цены предложения
- Отсутствуют обработчики:
  - `offer:filesUploaded` - загрузка файлов к предложению
  - `offer:paid` - оплата предложения

## Целевое состояние
- Новая схема: `grid-cols-1 lg:grid-cols-4` (список чатов | окно чата | панель предложений)
- Offers отображаются в отдельной колонке справа от чата
- Список предложений с скроллом при множественных предложениях
- Полная обработка всех WebSocket событий связанных с предложениями

## План реализации

### Этап 1: Изменить сетку в chat/page.tsx
- Изменить `grid-cols-3` на `grid-cols-4`
- Добавить новую колонку для offers после ChatWindow
- Адаптивность: показывать только на `lg` и выше

### Этап 2: Убрать отображение offers из ChatWindow
- Удалить блок `{offers.map(...)}` из ChatWindow.tsx (строки 265-272)
- Убрать `offers` из пропсов ChatWindow или оставить для совместимости

### Этап 3: Создать компонент OffersPanel
- Создать новый компонент `OffersPanel.tsx` для отображения списка предложений
- Использовать существующий компонент OfferCard для рендеринга каждого предложения
- Добавить скроллируемый контейнер с фиксированной высотой
- Показывать пустое состояние если предложений нет

### Этап 4: Передать offers в новую колонку
- В chat/page.tsx добавить компонент OffersPanel в новую 4-ю колонку
- Передать offers, currentUserId, onAccept, onDecline

### Этап 5: Добавить отсутствующие WebSocket обработчики в ChatContext
Добавить обработчики для событий:
- `offer:filesUploaded` - при загрузке файлов к предложению обновлять состояние
- `offer:paid` - при оплате предложения обновлять состояние

### Этап 6: Адаптивность
- На мобильных устройствах скрывать панель предложений
- Показывать только на `lg` и выше (десктоп)

## Изменяемые файлы
1. `front/src/app/[lang]/chat/page.tsx` - изменить сетку, добавить компонент
2. `front/src/components/chat/ChatWindow.tsx` - убрать рендеринг offers
3. Создать `front/src/components/chat/OffersPanel.tsx` - новый компонент
4. `front/src/context/chat/ChatContext.tsx` - добавить WebSocket обработчики

## WebSocket события для предложений
| Событие | Описание | Действие |
|---------|----------|----------|
| `offer:created` | Новое предложение создано | Добавить в список |
| `offer:statusChanged` | Изменен статус (pending/accepted/declined) | Обновить в списке |
| `offer:priceChanged` | Изменена цена | Обновить в списке |
| `offer:filesUploaded` | Загружены файлы | Обновить в списке |
| `offer:paid` | Предложение оплачено | Обновить в списке |
